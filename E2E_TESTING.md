# E2E-тесты CodeBug

Набор проверяет критические пользовательские сценарии через настоящий браузер Playwright:

- регистрация и экран подтверждения email;
- восстановление пароля, вход и выход;
- открытие задачи, отправка решения и отображение вердикта;
- профиль и статистика;
- регистрация в соревновании, открытие задачи, ограничения FREE и создание приватного соревнования в PRO+.

Тесты не используют продовый Firebase, почту, reCAPTCHA или judge. Они запускают страницы локально и подменяют внешние сервисы детерминированным тестовым стендом, поэтому безопасны для запуска на компьютере и в CI.

```bash
npm install
npx playwright install chromium
npm run test:e2e
```

Для визуального запуска браузера:

```bash
npm run test:e2e:headed
```

Если на macOS уже установлен Google Chrome, можно не скачивать Chromium:

```bash
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e
```

Рекомендуется запускать этот набор перед релизом. Отдельный staging-набор с Firebase Emulator и Docker runner нужен дополнительно, чтобы проверять настоящую доставку email и реальное выполнение решений.
