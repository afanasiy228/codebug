# Telegram Admin Bot

Бот показывает состояние CodeBug в личных чатах и группах, отправляет алерты и позволяет подтверждать задачи. Токен, Telegram ID и webhook secret хранятся только в переменных окружения Render.

## 1. Обязательно заменить токен

Если токен когда-либо отправлялся в чат или попадал в лог, откройте `@BotFather`, выполните `/revoke` и получите новый. Старый токен использовать нельзя.

## 2. Узнать ID

1. Telegram ID администраторов можно узнать через `@userinfobot`.
2. Сначала заполните `TELEGRAM_ADMIN_IDS` и добавьте бота в группу.
3. В группе выполните `/settings@имя_бота`. Ответ содержит отрицательный Chat ID группы.
4. Добавьте этот ID в `TELEGRAM_ALLOWED_CHAT_IDS` и `TELEGRAM_ALERT_CHAT_IDS`.

Privacy Mode можно оставить включённым: slash-команды и нажатия inline-кнопок бот получает. Делать бота администратором группы не требуется.

## 3. Переменные Render

Скопируйте названия из `.env.example` и заполните:

- `TELEGRAM_BOT_TOKEN` — новый токен BotFather;
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из 32+ символов `A-Z`, `a-z`, `0-9`, `_`, `-`;
- `TELEGRAM_ADMIN_IDS` — Telegram ID администраторов через запятую;
- `TELEGRAM_ALLOWED_CHAT_IDS` — разрешённые группы через запятую;
- `TELEGRAM_ALERT_CHAT_IDS` — личные чаты/группы, куда отправлять алерты;
- `TELEGRAM_MONITOR_ENABLED=1` — включить внутренние проверки.

После deploy локально экспортируйте те же переменные и один раз выполните:

```bash
python3 scripts/setup_telegram_bot.py
```

Скрипт установит `https://codebug.onrender.com/telegram/webhook` и меню команд. Сам токен в вывод не попадает.

## 4. Команды

- `/help` — полный гайд;
- `/status`, `/health` — общее состояние;
- `/queue` — очередь judge;
- `/errors` — последние ошибки текущего процесса;
- `/submissions 24` — решения за указанное число часов;
- `/users` — число пользователей и регистраций;
- `/payments` — статусы платежей за сутки;
- `/tasks` — подтверждённые и ожидающие задачи;
- `/task 27` — карточка задачи и кнопка подтверждения;
- `/deploy` — commit, ветка и uptime;
- `/mute 30m`, `/unmute` — управление некритичными алертами;
- `/settings` — Chat ID и текущие настройки.

В группе подходят обе формы: `/status` и `/status@имя_бота`. Любая команда дополнительно проверяет Telegram ID отправителя; видимость команды в меню не предоставляет доступ.

## 5. Внешняя проверка падения

Внутренний bot monitor не может отправить сообщение, если весь Render упал. Поэтому `scripts/telegram_uptime_monitor.py` нужно запустить отдельным worker/cron на другом хостинге:

```bash
python3 scripts/telegram_uptime_monitor.py
```

Для проверки конфигурации один раз:

```bash
python3 scripts/telegram_uptime_monitor.py --once
```

Watcher ждёт несколько ошибок подряд, сообщает о падении один раз, затем отдельно сообщает о восстановлении. Также проверяется срок TLS-сертификата.

## Безопасность

- webhook принимает запрос только с правильным `X-Telegram-Bot-Api-Secret-Token`;
- команды работают только для `TELEGRAM_ADMIN_IDS`;
- группы при заполненном списке ограничены `TELEGRAM_ALLOWED_CHAT_IDS`;
- бот не показывает email, UID, токены, код решений и платёжные реквизиты;
- изменение подписок, рейтинга, пользователей и перезапуск сервера через Telegram запрещены;
- модерация задач записывается в `adminAudit/telegram`.
